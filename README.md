# OAS3-BRCA-Bioinformatics
# OAS3 Expression and Functional Characterization in TCGA Breast Cancer (BRCA)
OAS3 is an interferon-stimulated antiviral gene that has recently been identified as a potential pan-cancer biomarker. A previous pan-cancer study demonstrated associations between OAS3 expression, immune infiltration, prognosis, and antiviral signaling across multiple malignancies.
This repository reproduces and extends key findings from a published pan-cancer analysis of OAS3 using TCGA Breast Cancer (BRCA) RNA-seq data obtained from the UCSC Xena platform.

# Objectives
- Evaluate OAS3 expression in breast tumors and normal tissue
- Assess prognostic significance using Kaplan-Meier analysis
- Identify genes co-expressed with OAS3
- Perform functional enrichment analyses
- Compare findings with the published pan-cancer study
- Identify differentially expressed genes between OAS3-high and OAS3-low tumors
